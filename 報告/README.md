# 平行程式設計｜報告與連結

本資料夾收錄課程專案提案、期末報告，以及作業壓縮檔中附帶的 HackMD／專案連結。

## 內容

- `Proposal_Report.pdf`：平行化專案提案。
- `Final_Report.pdf`：期末專案報告，從課程提交的 `20.zip` 解壓整理而來。
- `HW1_HackMD.md`、`HW2_HackMD.md`：作業壓縮檔內的 HackMD 檢視連結。
- `Final_Project_Link.md`：期末專案程式碼 repository 連結。

原始 HW1 壓縮檔中的連結是 HackMD 編輯網址；為避免公開編輯權限，這裡使用相同文件的檢視網址。
